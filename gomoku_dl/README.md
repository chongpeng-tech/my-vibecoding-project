# 五子棋人机对战（Python）

## 运行方式

```bash
python gomoku_dl/gomoku_game.py
```

## 已实现能力

- 15x15 标准棋盘，玩家黑棋，电脑白棋
- 鼠标点击落子，自动判定五子连珠胜负
- 支持悔棋（回退两步）与重新开始
- 显示当前手数与状态提示（包括“电脑思考中…”）
- AI 使用 Minimax + Alpha-Beta，默认搜索深度 4
- Threat Space Search：优先处理活四 / 冲四 / 活三 / 眠三
- 棋型评分包含：活四(100000)、冲四(10000)、活三(5000)、眠三(500)、活二(100)
- 含简化开局库（前几手经典中心定式）
- 木纹棋盘、棋子高光阴影、落子动画、最后落子高亮

## 说明

- 代码中的 `DeepPolicyNet` 是一个轻量“深度策略网络”前向推理模块，
  用于候选走子排序，与博弈树搜索结合，形成“深度学习 + Minimax”混合策略。
- UI 使用 Tkinter，异步通过 `after + threading` 实现，避免 AI 思考时界面卡死。
